# VIDEO PRODUCTION SPEC — กรอกข้างบน แล้วอ่านลงมา

ไฟล์เดียวจบสำหรับงานวิดีโอ AI: **แก้เฉพาะบล็อก SETTINGS** ที่หัวไฟล์ ทุกอย่างใต้เส้นคำนวณจากค่านั้น
บอกว่าต้องเจนอะไร กี่ชิ้น ด้วยโมเดลไหน ฟรีหรือเสียเงิน และส่ง request หน้าตายังไง

> ราคาทุกตัวในไฟล์นี้ **วัดจริงด้วย `get_cost` เมื่อ 2026-08-04 บนแพลน Plus**
> ราคาเปลี่ยนได้ — ก่อนเริ่มงานใหญ่ให้ยิง `get_cost: true` หนึ่งครั้งเพื่อยืนยัน อย่าเชื่อไฟล์นี้อย่างเดียว

---

## 1. SETTINGS — แก้แค่ตรงนี้

```yaml
# --- เรื่อง ---
title:            "นายขนมต้ม"          # ชื่อเรื่อง/โปรเจกต์
topic:            "เชลยศึกสยามที่ถูกสั่งให้ขึ้นชกในงานสมโภชของราชสำนักพม่า"
language:         th                     # ภาษาพากย์และซับ
genre:            short-drama            # short-drama | documentary | explainer | story

# --- ขนาดงาน ---
ep_count:         10                     # จำนวนตอน (1 = คลิปเดี่ยว)
ep_minutes:       1                      # ความยาวต่อตอน (นาที)
clip_seconds:     15                     # ความยาวต่อคลิปที่โมเดลเจนได้

# --- สเปกภาพ ---
aspect:           "9:16"                 # 9:16 แนวตั้ง | 16:9 แนวนอน
resolution:       "720p"
video_model:      seedance_2_0           # ดูตาราง §3
video_mode:       std                    # std | fast | mini  — งานสมจริงต้อง std (§13-5)
bitrate_mode:     high                   # high = ลด compression mush บนภาพสมจริง
look:             live-action            # live-action | stylized  — ดู §6.4
# ห้ามใส่คำว่า cinematic / epic / 8k / hyperrealistic ลงในช่องนี้ — มันคือคำที่ดึงไป CG (§13-5)

# --- เสียง ---
native_audio:     false                  # false = ปิดเสียงโมเดล ทำ SFX เองตอนตัด (§13-1, §13-4)
music:            false
vo_engine:        elevenlabs             # elevenlabs (นอกระบบ) | seed_audio (ในระบบ)
subtitles:        true

# --- นักแสดง/สถานที่/เครื่องแต่งกาย ---
characters:       2                      # ตัวละครที่ต้องหน้าเหมือนกันทุกตอน
locations:        4                      # ฉากหลักที่ใช้ซ้ำ
costumes:         2                      # ชุดของกลุ่มคนที่ไม่ใช่ตัวเอก — ต้องมี sheet (§13-3)
crowd_sheet:      true                   # true ถ้ามีฉากที่มีคนหลายคนในเฟรม (§13-2)

# --- งบ ---
credits_on_hand:  781.5
```

## 2. ตัวเลขที่คำนวณได้ทันที

| ค่า | สูตร | ตัวอย่างจาก SETTINGS ข้างบน |
|---|---|---|
| ความยาวรวม | `ep_count × ep_minutes × 60` | 600 วินาที (10 นาที) |
| คลิปต่อตอน | `ceil(ep_minutes × 60 ÷ clip_seconds)` | 4 |
| **คลิปทั้งหมด** | `ep_count × คลิปต่อตอน` | **40** |
| บรรทัดพากย์ | `= คลิปทั้งหมด` (1 บรรทัด/คลิป) | 40 |
| คีย์เฟรม | `= คลิปทั้งหมด` | 40 |
| Character sheet | `= characters` | 2 |
| Location sheet | `= locations` | 4 |
| Costume sheet | `= costumes` | 2 |
| Crowd sheet | `crowd_sheet ? 1 : 0` | 1 |
| **ภาพที่ต้องเจนรวม** | `คีย์เฟรม + characters + locations + costumes + crowd` | **49** |
| เครดิตค่าคลิป | `คลิปทั้งหมด × clip_seconds × อัตรา/วินาที (§3)` | 40 × 15 × 4.5 = **2,700** |
| เครดิตค่าภาพ | `ภาพรวม × 0.12` (soul_2) | ~6 |
| **ทำได้กี่คลิปด้วยเครดิตที่มี** | `floor(credits_on_hand ÷ ราคา/คลิป)` | 781.5 ÷ 67.5 = **11 คลิป** |
| **ทำได้กี่ตอนเต็ม** | `floor(ข้างบน ÷ คลิปต่อตอน)` | **2 ตอน** |

> ถ้าเครดิตไม่พอทั้งซีรีส์ **ให้ทำทีละตอนจนจบตอน** อย่าเจนครึ่ง ๆ กลาง ๆ ทุกตอน
> ตอนที่ไม่ครบทุกคลิปคือตอนที่ปล่อยไม่ได้ = เครดิตที่จ่ายไปเปล่า

## 4. ลำดับการเจน — ทำตามลำดับนี้เท่านั้น

| # | ขั้น | จำนวน | โมเดล | ราคา | ผ่านแล้วไปต่อได้เมื่อ |
|---|---|---|---|---|---|
| 1 | **Character sheet** | `characters` | `soul_2` 16:9 | ฟรี | หน้า/ทรงผม/เครื่องแต่งกาย นิ่งพอจะใช้อ้างอิงได้ทั้งเรื่อง |
| 2 | **Costume sheet** | `costumes` | `soul_2` 16:9 | ฟรี | ชุดของกลุ่มที่ไม่ใช่ตัวเอก **ห้ามข้าม** ไม่งั้นได้ชุดผิดชาติ (§13-3) |
| 3 | **Crowd sheet** | 1 (ถ้ามีฉากคนเยอะ) | `soul_2` ตาม `aspect` | ฟรี | คน 5–8 คน หน้าตาต่างกันชัด กัน identity bleed (§13-2) |
| 4 | **Location sheet** | `locations` | `soul_2` หรือ seedream, ตาม `aspect` | ฟรี | โทนสีและยุคสมัยตรงกันทุกใบ |
| 5 | **คีย์เฟรม** | `= คลิปทั้งหมด` | เดียวกับข้อ 1 + แนบ sheet | ฟรี | เรียงแล้วอ่านเป็นเรื่องได้โดยไม่ต้องมีเสียง |
| 6 | **ตรวจ storyboard** | — | — | ฟรี | **ประตูเงิน — ห้ามข้าม** ดูเกณฑ์ใต้ตาราง |
| 7 | **คลิปทดสอบ 1 อัน** | 1 | `video_model` | เสียเงิน 1 คลิป | **ประตูเงินที่สอง** ผ่านแล้วค่อยยิงที่เหลือ (§13-6) |
| 8 | **คลิปที่เหลือ** | `= คลิปทั้งหมด − 1` | `video_model` | เสียเงิน | ทำทีละตอนจนครบตอน |
| 9 | **พากย์** | `= คลิปทั้งหมด` | `vo_engine` | ขึ้นกับ engine | เสียงเดียวตลอดเรื่อง ล็อก voice id |
| 10 | **SFX + ตัดต่อ + ซับ** | — | นอกระบบ | — | ทำเสียงบรรยากาศเส้นเดียวยาวทั้งตอน แล้ววาง spot SFX ทับ (§13-4) |

**ประตูเงินที่หนึ่ง (ข้อ 6) ต้องผ่านสามข้อนี้ก่อนจ่ายเงิน:**
1. ภาพนิ่ง **ดูเหมือนภาพถ่ายจริง ไม่ใช่ CG** — ถ้าภาพนิ่งยังเป็นเกม คลิปจะเป็นเกมแน่นอน (§13-5ข)
2. หน้าตัวละครตรง sheet และ **คนอื่นในเฟรมหน้าไม่ซ้ำกับตัวเอก**
3. เครื่องแต่งกายตรง costume sheet ไม่ใช่ชุดของชาติอื่น

**ทำไมสองประตูนี้ถึงสำคัญ:** ข้อ 1–6 ฟรีทั้งหมด ข้อ 8 คือทั้งงบ
ทุกความผิดพลาดที่จับได้ก่อนข้อ 7 ราคาศูนย์ · ที่จับได้ตอนข้อ 7 ราคา 1 คลิป · ที่จับได้ตอนข้อ 8 ราคายกตอน

## 5. Request ที่ต้องส่ง

### 5.1 พรีเช็คราคา (ทำก่อนเสมอ — ไม่ส่งงาน ไม่หักเครดิต)
```json
{ "params": { "model": "seedance_2_0", "prompt": "cost probe", "duration": 15,
  "resolution": "720p", "mode": "std", "aspect_ratio": "9:16", "get_cost": true } }
```

### 5.2 Character sheet (ฟรี)
```json
{ "params": { "model": "soul_2", "aspect_ratio": "16:9", "quality": "2k",
  "prompt": "<§6.1>" } }
```

### 5.3 คีย์เฟรม (ฟรี) — แนบ sheet เป็น reference
```json
{ "params": { "model": "soul_2", "aspect_ratio": "9:16",
  "prompt": "<ช็อตแรกของคลิปนั้น> <§6.4 BASE LOOK>",
  "medias": [ { "role": "image", "value": "<character_sheet_job_id>" } ] } }
```

### 5.4 คลิป (เสียเงิน) — ยิงทีละชุดไม่เกิน 12
```json
{ "requests": [ { "index": 1, "params": {
  "model": "seedance_2_0", "mode": "std", "duration": 15,
  "resolution": "720p", "aspect_ratio": "9:16",
  "bitrate_mode": "high", "generate_audio": false, "genre": "drama",
  "prompt": "<§6.3 จังหวะตัด> <§6.4 BASE LOOK>",
  "medias": [
    { "role": "start_image",      "value": "<keyframe_job_id>" },
    { "role": "image_references", "value": "<location_sheet_job_id>" },
    { "role": "image_references", "value": "<costume_sheet_job_id>" } ] } } ] }
```
เครื่องมือ: `generate_video_batch` → `jobs_wait` (ทีละ ≤12) → `show_generation_by_ids` ครั้งเดียว

> **สังเกตว่า character sheet ไม่ได้อยู่ในตัวอย่างนี้** — ตัวอย่างนี้คือช็อตที่มีคนหลายคน
> ส่ง `CH` เข้าไปเมื่อไหร่ ทุกคนในเฟรมจะได้หน้าเดียวกัน (§13-2)
> ช็อตที่ตัวเอกอยู่คนเดียวเท่านั้นถึงจะส่ง `CH` และเมื่อส่งแล้ว **ให้ส่งเป็นตัวแรกของ `image_references`**

### 5.5 ขอใช้โควต้าฟรี
เติม `"use_unlim": true` ในทุก request ของรอบนั้น **ส่งไปเลย อย่าไปเช็คก่อนว่ามีสิทธิ์ไหม** —
ระบบตอบกลับเป็น error ที่อ่านออก ไม่หักเงินเงียบ ๆ

| error ที่ได้ | แปลว่า | ทำยังไงต่อ |
|---|---|---|
| `unlim_trial_available` | มีสิทธิ์ แต่ยังไม่เปิด | เรียก `show_plans_and_credits` แล้วรอผู้ใช้ |
| `unlim_trial_expired` / `unlim_not_eligible` | สิทธิ์หมด/ไม่มี | **หยุด ถามก่อน** ว่าจะจ่ายเครดิตต่อไหม |
| `unlim_not_supported` | โมเดลนี้ไม่มีทางฟรี | เปลี่ยนโมเดลหรือยอมจ่าย |
| `unlim_config_not_covered` | โมเดลฟรี แต่ค่าที่ตั้งไม่อยู่ในสิทธิ์ | ลดความยาว/ความละเอียดให้เข้ากรอบ |

## 6. เทมเพลต prompt

### 6.1 Character sheet
```
Split-screen character sheet composition, left side a full-body shot standing
upright facing camera, both feet flat, arms relaxed, full head-to-toe framing,
right side a tight chest-up portrait of the same character, identical original
character on both sides, single subject only exactly one person, pure white
seamless studio background,
[อายุ + ผิว], [รูปหน้า ขากรรไกร โหนกแก้ม จมูก ปาก], [ตา + naturally muted
catchlights, no artificial glare], [คิ้ว], [ผม: สี ความยาว ทรง ความมัน],
visible fine skin texture with natural pores, uneven tone, old scars, calloused
hands, slight natural sweat sheen, no digital smoothing, no beauty filter,
no AI-airbrushed look,
[รูปร่าง], wearing [บนล่างครบ: เสื้อ → ชั้นนอก → ท่อนล่าง → คาดเอว → รองเท้า →
เครื่องประดับ], natural anatomy, unretouched documentary photography style,
soft diffused studio lighting, cinematic realism, 4K, sharp focus on skin texture,
single subject only, no other people, no duplicate figures, no mannequin, no props,
no furniture, left panel standing full-body not cropped not sitting, right panel
tight close-up not full body, no babyface, original character not resembling any
real person, no text, no watermark, no logos, no frame borders.
```
**กติกา:** ตัวละครต้องเป็นตัวละครออริจินัลเสมอ · ห้ามอ้างอิงหน้าคนจริงหรือ IP ที่มีลิขสิทธิ์ ·
ตัวละครผู้ใหญ่ต้องระบุโครงหน้าผู้ใหญ่ ไม่งั้นโมเดลจะออกมาหน้าเด็ก ·
แก้ครั้งต่อไปต้องเขียนรายละเอียดเดิมซ้ำทั้งหมด เปลี่ยนเฉพาะสิ่งที่ตั้งใจเปลี่ยน

### 6.2 Location sheet
```
[สถานที่ + ยุคสมัย + เวลาของวัน + สภาพอากาศ], [วัสดุและรายละเอียดที่มองเห็น],
[ทิศทางแสง], empty of people, wide establishing frame.
+ §6.4 BASE LOOK
```

### 6.3 คลิป — จังหวะตัด + ELEMENTS + SFX ต้องอยู่ **ใน prompt** ทั้งหมด

อย่าเก็บ element กับ SFX ไว้แค่ในเอกสารข้างนอก **เขียนลงไปใน prompt ที่ส่งให้โมเดลจริง ๆ**
โมเดลอ่านมันแล้วใช้จัดฉาก จัดเสียง และรักษาความต่อเนื่องให้ ถ้าไม่เขียน มันจะเดาเอง

```
ELEMENTS: [LOC-## ชื่อสถานที่ + เวลาของวัน + อากาศ] | [CH-## ตัวละคร +
สภาพ WD-## ณ คลิปนี้] | [PR-## พร็อพที่ต้องเห็นในเฟรม] | [สิ่งที่ห้ามมีในเฟรม]
CAMERA: [เลนส์] [การเคลื่อนกล้อง] [ไล่ขนาดภาพ]
LIGHT: [แหล่งแสง] [ทิศทาง] [มี/ไม่มีแสงเติม]
EMOTION: [คนดูควรรู้สึกอะไร] · [ใครทำอะไรกับใคร เป็นการกระทำที่ถ่ายติด] ·
[ตัวเอกอยู่ตรงไหน ทำอะไรไม่ได้] · [จบคลิปโดยยังไม่มีใครชำระหนี้] — ดู §14

SHOT A (0-2s)  [ขนาดภาพ] [มุม]: [สิ่งที่เกิดขึ้น]
SHOT B (2-5s)  [ขนาดภาพ] [มุม]: [สิ่งที่เกิดขึ้น]
SHOT C (5-8s)  ...
SHOT D (8-11s) ...
SHOT E (11-15s)...

SFX: [ชั้นตัวละคร: หายใจ ฝีเท้า ผ้า เสียงพยายาม] + [ชั้นสภาพแวดล้อม: ลม ไฟ
ฝูงชน น้ำ room tone] + [ชั้นเน้นจังหวะ: กระแทก ของตก โลหะ หรือความเงียบ]
พร้อมบอกว่าเสียงไหนอยู่ช็อตไหน — เช่น "impact on SHOT C, silence over SHOT E"
+ §6.4 BASE LOOK
```

**ตัวอย่างที่กรอกแล้ว (คลิป 15 วิ 9:16)**
```
ELEMENTS: LOC-02 prisoner compound at night, no wind, packed dirt |
CH-01 the fighter, WD-02 state: dusty loincloth, no facial wounds yet |
PR-03 hemp rope hand-wraps, PR-05 a dying cooking fire |
nothing modern in frame, no other people visible

CAMERA: 35mm, light handheld, ECU -> MEDIUM -> WIDE progression
LIGHT: single low side firelight, no fill, background falls to pure black

SHOT A (0-3s) ECU: a rope wrap tightening around a fist, fibres catching.
SHOT B (3-6s) LOW ANGLE: bare feet settling into a fighting stance on dirt.
SHOT C (6-9s) MEDIUM SILHOUETTE: a slow controlled knee and elbow sequence,
  no opponent, mouth closed, characters do not speak.
SHOT D (9-12s) MACRO: sweat running down a scarred forearm in firelight.
SHOT E (12-15s) WIDE: him alone in the centre of the empty compound, motion
  starts on frame one and never stops.

SFX: steady controlled breathing through the nose and rope fibres creaking
(character layer) + faint fire crackle and distant night insects (ambient
layer) + one sharp cloth snap on the elbow at SHOT C, then near-silence with
only breath over SHOT E (accent layer). No music, no melody, no drums.
```

**กติกา:**
- **ทุก prompt ต้องมีบรรทัด `ELEMENTS` `CAMERA` `LIGHT` `EMOTION` `SFX` ครบห้าบรรทัด** ช่องที่ไม่มีให้เขียน `none` ห้ามลบบรรทัดทิ้ง
- **`EMOTION` ต้องเป็นการกระทำ ไม่ใช่คำคุณศัพท์** `cruel villain` ได้ผลศูนย์ ดู §14.1
- **`ELEMENTS` ต้องมีท่อน "สิ่งที่ห้ามมีในเฟรม" เสมอ** — นี่คือท่อนที่กันของสมัยใหม่ ตัวประกอบที่ไม่ได้เรียก และตัวหนังสือ
- **`SFX` ต้องครบ 3 ชั้น และต้องผูกกับช็อต** เขียนแค่รายชื่อเสียงลอย ๆ โมเดลจะเกลี่ยเท่ากันหมดจนไม่มีจังหวะ
- **ความเงียบสั่งได้และควรสั่ง** — `near-silence over SHOT E` ให้ผลแรงกว่าเสียงดังในคลิปสั้น
- **`WD` ในบรรทัด ELEMENTS ต้องตรงกับสภาพสะสม ณ คลิปนั้น** ดูกติกา §7.3
- คลิป 15 วิ = 5–6 จังหวะ · **ห้ามช็อตไหนยาวเกิน 3 วินาที** ไม่งั้นได้สไลด์โชว์
- **นับรอยตัดที่ได้กลับมาจริง** ถ้าน้อยกว่าที่สั่ง ยิงซ้ำโดยเขียนช่วงเวลาย้ำอีกรอบ ครั้งเดียว
  ถ้ารอบสองยังไม่ได้ ปล่อยผ่าน แล้วจดว่าคลิปไหนช้า
- **เปลี่ยนขนาดภาพและมุมทุกจังหวะ** (WIDE / MEDIUM / CU / ECU / low / high / overhead)
- **ห้ามเปิดทุกคลิปด้วย establishing wide เหมือนกัน**
- **ห้ามใช้ OTS กับช็อตที่ไม่มีคนอยู่ในเฟรม** โมเดลจะสร้างคนขึ้นมาเอง
- **ตัวละครห้ามขยับปากพูด** ถ้าใช้พากย์แยก → เขียน `characters do not speak, mouths closed`
- ต้องมีการเคลื่อนไหวตั้งแต่เฟรมแรก → เขียน `motion starts on frame one`
- **ช็อตที่มีคนมากกว่าหนึ่งคน ห้ามส่ง character reference เข้าไปเฉย ๆ** → §13-2 identity bleed
- **ห้ามเรียกเครื่องแต่งกายด้วยชื่อชาติ** (`Burmese soldier`, `Siamese guard`) → §13-3

### 6.4 BASE LOOK — ต่อท้ายทุก prompt ห้ามแก้ระหว่างเรื่อง

**เวอร์ชัน live-action** (ใช้เมื่อ `look: live-action`) — เขียนพฤติกรรมของกล้องจริง ไม่ใช่ชื่อรุ่นกล้อง

```
Live-action footage recorded on a large-format digital cinema camera with
spherical prime lenses at a wide stop. Real photographic behaviour: 180-degree
shutter motion blur on everything that moves, true optical depth of field with
focus falling off gradually across the frame, slight focus breathing on any
reframe, mild veiling flare and faint chromatic aberration only where a strong
practical light hits the glass, visible sensor noise in the shadows, highlights
that clip softly instead of glowing. Human imperfection: uneven skin with pores
and blemishes, sweat, dirt in the creases, stray hair, asymmetric faces, cloth
that hangs and creases under its own weight. Handheld micro-movement, slightly
imperfect framing, subjects occasionally a touch soft. Colour is muted and
photographic — [ระบุ 3–4 สี], no teal-and-orange grade, no colour cast, no glow,
no bloom. [ยุคสมัย/โลกของเรื่อง], no modern objects, no printed text in frame.

NOT: not a video game, not a game cinematic, not a game engine capture, not CGI,
not a 3D render, not animation, not anime, not concept art, not a matte painting,
no Unreal Engine look, no Octane render, no plastic or waxy skin, no smooth
flawless surfaces, no rim light on every subject, no volumetric god rays, no
floating particles, no over-saturated colour, no HDR look, no digital sharpening
halos, no airbrushing.
No on-screen text, no subtitles, no watermark, no logo.
```

**บรรทัด AUDIO ใส่ก็ต่อเมื่อ `native_audio: true` เท่านั้น**
```
AUDIO: diegetic sound effects only — no music, no score, no singing, no spoken
dialogue, no voiceover.
```
ถ้า `native_audio: false` **ห้ามใส่บรรทัดนี้เลย** การสั่งเรื่องเสียงในคลิปที่ปิดเสียงอยู่
ทำให้โมเดลเอา budget ไปคิดเรื่องที่ไม่ได้ใช้

> **คำที่ห้ามอยู่ใน prompt ของงาน live-action:** `cinematic` · `epic` · `dramatic lighting` ·
> `8k` · `4k` (ในเชิงคุณภาพ) · `hyperrealistic` · `ultra realistic` · `masterpiece` ·
> `unreal engine` · `octane` · `render` · `artstation` · `concept art` · `movie poster`
> คำพวกนี้อยู่ในชุดข้อมูลคู่กับภาพ CG และภาพเกม ยิ่งใส่ยิ่งได้เกม (§13-5)

### 6.5 Costume sheet — จำเป็นทุกครั้งที่มีกลุ่มคนที่ไม่ใช่ตัวเอก

```
Costume reference sheet, one person standing in a neutral pose, front view on the
left and back view on the right, plain mid-grey seamless background, even flat
lighting, full head-to-toe framing, face deliberately plain and unremarkable.
Garments, described by shape and material only:
[ท่อนบน: มี/ไม่มี · วัสดุ · ความยาว · แขน]
[ท่อนล่าง: ผ้าพัน/นุ่ง · ยาวถึงไหน · การเก็บชาย]
[ศีรษะ: โพก/ผูก/ไม่มี · ทรง]
[เท้า: เปล่า/รองเท้าแบบไหน]
[อาวุธและของพก: รูปทรง วัสดุ วิธีถือหรือสะพาย]
[เครื่องป้องกัน: มีหรือไม่มี ถ้ามี ทำจากอะไร]

not in frame: [ชุดของชาติที่โมเดลมักหลุดไปหา — ดู §13-3]
+ §6.4 BASE LOOK
```
**ห้ามใช้ชื่อชาติหรือชื่ออาณาจักรในบรรทัดไหนเลย** เขียนแต่รูปทรงและวัสดุ — นี่คือทั้งหมดของท่านี้

### 6.6 Crowd sheet — จำเป็นทุกครั้งที่มีคนเกินหนึ่งในเฟรม

```
A group of [5–8] different people standing together, full-body, plain seamless
background, even flat lighting. Every person is a visibly distinct individual:
different ages from young adult to elderly, different heights and builds,
different face shapes, different hair, different skin tones within the same
regional population. No two people resemble each other. No one in this image is
the protagonist. Wearing [ชุดตาม §6.5].
+ §6.4 BASE LOOK
```
ใบนี้ทำครั้งเดียวใช้ได้ทั้งเรื่อง มันคือคลังหน้าที่โมเดลจะหยิบไปแจกให้ตัวประกอบ
**แทนที่จะแจกหน้าตัวเอกให้ทุกคน**

## 7. ELEMENT — สิ่งที่สคริปต์ต้องกำกับทุกบรรทัด

สคริปต์ที่มีแต่คำพูดคือสคริปต์ที่ยังทำไม่ได้ **ทุกคลิปต้องประกาศ element ให้ครบ**
ไม่งั้นโมเดลจะคิดเอง แล้วเรื่องจะหลุดตั้งแต่คลิปที่สาม

### 7.1 ทะเบียน element

| รหัส | คืออะไร | ต้องทำ sheet ก่อนไหม |
|---|---|---|
| `CH-##` | ตัวละคร (ฝ่ายเรา) | **ต้อง** ทุกตัวที่โผล่เกิน 1 คลิป |
| `AN-##` | ตัวร้าย | **ต้อง** — หน้าต้องนิ่งทั้งซีรีส์ ไม่งั้นความเกลียดไม่สะสม (§14.4) |
| `EM-##` | อารมณ์เป้าหมายของคลิป | ไม่ต้อง แต่ต้องประกาศทุกคลิป (§14) |
| `LOC-##` | สถานที่ | **ต้อง** ทุกที่ที่ใช้ซ้ำ |
| `PR-##` | พร็อพ / วัตถุที่มีบทบาท | ต้อง ถ้าโผล่ ≥ 2 คลิป · โผล่ครั้งเดียวบรรยายใน prompt ได้เลย |
| `WD-##` | เครื่องแต่งกาย + **สภาพความเสียหาย** | ไม่ต้องทำแยก แต่ต้องประกาศทุกคลิป |
| `CAM-##` | เลนส์ · การเคลื่อนกล้อง · ไล่ขนาดภาพ | ไม่ต้อง |
| `LGT-##` | ทิศทางและแหล่งแสง | ไม่ต้อง |
| `SFX-##` | เสียงเอฟเฟกต์ | ไม่ต้อง แต่ต้องมีรายการ |
| `VO-##` | บรรทัดพากย์ | ไม่ต้อง |

**จำนวน sheet ที่ต้องเจน** = `characters + locations + พร็อพที่โผล่ ≥ 2 คลิป`

### 7.2 หน้าตาบรรทัดสคริปต์ที่ใช้ได้จริง

ทุกคลิปเขียนแบบนี้ **ครบทั้ง 8 ช่อง ช่องที่ไม่มีให้ใส่ `—` ห้ามเว้นว่าง**

```
[EP2 · CLIP 2 · 00:15–00:30]
VO-06 : "แต่ทุกคืนหลังไฟดับ เขาลุกขึ้นมาทำสิ่งเดียวที่ยังเป็นของเขาอยู่"
CH    : CH-01 นายขนมต้ม
WD    : WD-01 ผ้าเตี่ยวสภาพปกติ · ยังไม่มีบาดแผลบนใบหน้า
LOC    : LOC-02 ค่ายเชลย · กลางคืน · ไม่มีลม
PR    : PR-03 เชือกคาดมือ · PR-05 กองไฟที่กำลังจะดับ
CAM   : เลนส์ 35mm · แฮนด์เฮลด์เบา · ไล่ ECU → MEDIUM → WIDE
LGT   : กองไฟกองเดียว มาจากด้านข้างระดับต่ำ · ไม่มีแสงเติม · หลังดำสนิท
SFX   : SFX-04 ลมหายใจเป็นจังหวะ · SFX-07 เท้าบดดิน · SFX-02 ไฟแตกเบา
REF   : [CH-01, LOC-02, PR-03]   # ช็อตนี้มีคนเดียว จึงส่ง CH ได้ และส่งเป็นตัวแรก
```

`REF` คือสิ่งที่ส่งเข้า `image_references` **ลำดับ = ลำดับความสำคัญ ตัวแรกได้น้ำหนักมากที่สุด**
เพราะฉะนั้นลำดับไม่ตายตัว แต่ขึ้นกับว่าช็อตนั้นมีคนกี่คน:

| ชนิดช็อต | ส่งอะไร เรียงยังไง | เหตุผล |
|---|---|---|
| ตัวเอกอยู่คนเดียวในเฟรม | `CH` → `LOC` → `PR` | หน้าต้องชนะทุกอย่าง |
| มีคนหลายคน / ฝูงชน | `LOC` → `CROWD` → `WD` — **ห้ามส่ง `CH`** | ส่ง `CH` เมื่อไหร่ ทุกคนหน้าเหมือนกันหมด (§13-2) |
| ไม่มีคนในเฟรม (พร็อพ/สถานที่) | `LOC` → `PR` | ไม่มีอะไรให้ bleed |
| กลุ่มคนที่มีชุดเฉพาะ | `LOC` → `WD` (costume sheet) | ชุดต้องชนะ ไม่งั้นได้ชุดผิดชาติ (§13-3) |

**บรรทัดพวกนี้ไม่ได้อยู่แค่ในเอกสาร — มันแปลงตรงเข้า prompt** ตามตารางนี้:

| ช่องในสคริปต์ | ไปอยู่ตรงไหนของ prompt (§6.3) |
|---|---|
| `CH` + `WD` + `LOC` + `PR` | บรรทัด `ELEMENTS:` |
| `CAM` | บรรทัด `CAMERA:` |
| `LGT` | บรรทัด `LIGHT:` |
| `EM` | บรรทัด `EMOTION:` — แปลงเป็นการกระทำก่อนเสมอ (§14) |
| `SFX` | บรรทัด `SFX:` **ต้องระบุด้วยว่าเสียงไหนอยู่ช็อตไหน** |
| `REF` | ฟิลด์ `medias[]` ของ request ไม่ใช่ตัว prompt |
| `VO` | ไม่เข้า prompt เลย ไปเข้า TTS อย่างเดียว |

ถ้าช่องไหนในสคริปต์ว่าง แปลว่า prompt จะขาดบรรทัดนั้น แล้วโมเดลจะเติมเอง — นั่นคือจุดที่เรื่องหลุด

### 7.3 กติกาความต่อเนื่อง — ข้อที่พังบ่อยที่สุด

- **`WD` เดินหน้าอย่างเดียว ห้ามถอยหลัง** บาดแผล เลือด ผ้าขาด ฝุ่น ที่เกิดในคลิปที่ 12 ต้องอยู่ในคลิปที่ 13 ถึงจบเรื่อง
  → เขียน state ไล่ไว้ล่วงหน้าทั้งเรื่อง เช่น `WD-01 สะอาด → WD-02 ฝุ่นจับ → WD-03 คิ้วแตก → WD-04 ตาซ้ายปิด`
- **`LOC` เดิมติดกันไม่เกิน 2 คลิป** แล้วต้องเปลี่ยนที่ หรืออย่างน้อยเปลี่ยนมุมและระยะ ไม่งั้นคนดูรู้สึกว่าเรื่องหยุดเดิน
- **`CH` ที่โผล่ครั้งแรกต้องมี sheet ก่อนเสมอ** ห้ามปล่อยให้โมเดลออกแบบหน้าคนใหม่กลางเรื่อง
- **`PR` ที่มีบทบาทต้องมีที่มาที่ไป** ของที่โผล่มาในมือโดยไม่เคยเห็นว่าได้มาจากไหน คือรอยรั่วที่คนดูจับได้
- **`SFX` ต้องมีอย่างน้อย 3 ชั้นต่อคลิป**: เสียงจากตัวละคร (หายใจ ฝีเท้า ผ้า) + เสียงสภาพแวดล้อม (ลม ไฟ ฝูงชน) + เสียงเน้นจังหวะ (กระแทก ของตก ความเงียบ)
  → **ความเงียบนับเป็น SFX** ใส่ `SFX-00 เงียบสนิท 2 วินาที` ได้ และมักได้ผลกว่าเสียงดัง
- **`CAM` ห้ามซ้ำสองคลิปติด** ถ้าคลิปก่อนเป็นแฮนด์เฮลด์ คลิปนี้เป็นล็อกช็อตหรือดอลลี่

### 7.4 element ที่ห้าม drift ทั้งเรื่อง

เขียนไว้ครั้งเดียวที่ §6.4 แล้ว **ห้ามแก้ระหว่างเรื่องเด็ดขาด**: BASE LOOK · พาเลตต์สี · หน้าตัวละคร ·
ยุคสมัยและวัตถุที่อนุญาตให้อยู่ในเฟรม · กติกาเสียง (มี/ไม่มีดนตรี)
ถ้าจำเป็นต้องแก้จริง ๆ ต้องเจนใหม่ทั้งตอน ไม่ใช่แก้เฉพาะคลิปเดียว

### 7.5 ตรวจก่อนส่งสคริปต์เข้าโปรดักชัน

- [ ] ทุกคลิปมีครบ 9 ช่อง (รวม `EM`) ไม่มีช่องว่างเปล่า
- [ ] ทุก `EM` เขียนเป็นการกระทำที่ถ่ายติด ไม่ใช่คำคุณศัพท์ (§14.1)
- [ ] ความโหดผูกกับ `AN-##` ตัวบุคคล ไม่ใช่กับชาติหรือกลุ่ม (§14.5)
- [ ] ทุก `CH` และ `LOC` ที่ปรากฏ มี sheet แล้ว
- [ ] `WD` ไล่ต่อเนื่องตั้งแต่คลิปแรกถึงคลิปสุดท้าย ไม่มีจุดที่ความเสียหายหายไป
- [ ] ไม่มี `LOC` เดียวกันติดกันเกิน 2 คลิป
- [ ] ทุกคลิปมี `SFX` ครบ 3 ชั้น
- [ ] `REF` ของทุกคลิปเรียงถูกตามชนิดช็อต และ **ช็อตที่มีคนหลายคนไม่มี `CH` อยู่ใน REF**
- [ ] `PR` ทุกชิ้นมีที่มา ไม่มีของโผล่มาลอย ๆ

## 8. โครงเรื่อง — 6 ช่อง

ทุกงาน ทุกความยาว ต้องครบหกช่อง ความยาวเปลี่ยนขนาดช่อง ไม่เปลี่ยนจำนวนช่อง

| ช่อง | คืออะไร | ตกช่องนี้แล้วเป็นยังไง |
|---|---|---|
| 1 **ฐาน** | สภาพเดิม + ความเชื่อที่คนดูถืออยู่ | คนดูไม่รู้ว่าอะไรเปลี่ยน |
| 2 **สะดุด** | สิ่งที่ขัดกับความเชื่อนั้น | ไม่มีคนดู |
| 3 **ช่องว่าง** | คำถามที่ยังไม่ตอบ | คนดูไม่มีเหตุผลจะอยู่ต่อ |
| 4 **บีบ** | ลองแล้วไม่ได้ผล สถานการณ์แคบลง | กลายเป็นรายการสอนทำอาหาร |
| 5 **จ่าย** | ต้องเลือกสิ่งที่ไม่อยากเลือก | ตอนจบไม่มีใครเชื่อ |
| 6 **ลง** | สภาพใหม่ + สิ่งที่คนดูได้ติดตัว | จบแบบไม่รู้ว่าจบทำไม |

### วางหกช่องลงบนจำนวนตอน
| `ep_count` | การกระจาย |
|---|---|
| 1 | ทั้งหกช่องอยู่ในคลิปเดียว สะดุดต้องมาก่อนวินาทีที่ 3 |
| 3–5 | ตอน 1 = ฐาน+สะดุด+ช่องว่าง · ตอนกลาง = บีบ · ตอนสุดท้าย = จ่าย+ลง |
| 6–12 | ตอน 1 = ฐาน+สะดุด · ตอน 2 = ช่องว่าง · ตอน 3 ถึง `n-1` = บีบแบ่งเป็นองก์ **แต่ละองก์จบด้วยความล้มเหลวที่แพงกว่าเดิม** · ตอนสุดท้าย = จ่าย+ลง |

**และทุกตอนต้องครบหกช่องในตัวเองด้วย** ซีรีส์มีหกช่องหนึ่งชั้น ตอนมีอีกชั้น

### กติกาที่ห้ามพลาด
- **สะดุดมาก่อนเสมอ** — คลิปสั้น: ก่อนวินาทีที่ 3 · คลิปยาว: ใน 15 วินาทีแรก
- **คลิปยาวเกิน 3 นาที: ย้ำช่องว่างด้วยคำถามที่แคบลงทุก ~90 วินาที** ไม่งั้นคนออกกลางทาง
- **ทุกตอนของซีรีส์จบด้วย cliffhanger** ที่ยังไม่ตอบ และตัดดำทันที ห้ามเฟด
- **ช่องจ่ายต้องมาก่อนจบอย่างน้อย 60 วินาที** ไม่งั้นตอนจบรู้สึกรีบ
- **เชื่อมด้วย "แต่" หรือ "เพราะฉะนั้น" ≥ 2 จุด** ถ้าเชื่อมด้วย "แล้วก็" ทั้งเรื่อง = รายงาน ไม่ใช่เรื่อง
- **CTA เดียว โตออกมาจากช่องลง** ตัดทิ้งแล้วเรื่องยังจบสมบูรณ์ = วางถูก
- **ตัวเอกคือคนดูหรือคนในเหตุการณ์** แบรนด์เป็นเครื่องมือ ไม่ใช่พระเอก

## 10. ความจริงและความปลอดภัย

- **ห้ามแต่งตัวเลข ชื่อเคส คำพูด ผลลัพธ์** ที่ไม่มีข้อมูลจริง → เขียนเป็น `[ต้องยืนยัน: …]` แล้วเล่าต่อรอบช่องนั้น
- **แยกให้ชัดระหว่างหลักฐานกับเรื่องเล่า** เอาเรื่องเล่ามาทำหนังได้ แต่**ห้ามเขียนเป็นข้อเท็จจริงในแคปชั่น** ให้ใช้ "ตามที่เล่าสืบกันมา"
- **งานประวัติศาสตร์ไทย: ห้ามวาดพระพักตร์พระมหากษัตริย์และพระบรมวงศานุวงศ์** ใช้ห้องท้องพระโรงว่าง เงา หรือสัญลักษณ์แทน
- **ห้ามอ้างอิงหน้าคนจริงหรือ IP ที่มีลิขสิทธิ์** ภาพอ้างอิงที่ผู้ใช้อัปโหลดใช้เป็น "ตัวอย่างสไตล์" เท่านั้น
- **ไม่ใส่ข้อมูลส่วนตัวหรือความลับลงใน prompt**
- **งานสายสุขภาพ/คลินิก:** ห้ามเขียนคำรับประกันผลหรือกรอบเวลาที่เอกสารอ้างอิงไม่ได้พูดไว้

## 13. อาการที่เจอจริง → สาเหตุ → วิธีแก้

บันทึกจากการรันจริง ไม่ใช่การเดา ทุกข้อระบุว่าต้องแก้ที่ **ขั้นไหน** เพราะหลายข้อแก้ที่ prompt ไม่ได้

| # | อาการ | สาเหตุจริง | แก้ที่ขั้น |
|---|---|---|---|
| 1 | เสียงระหว่างคลิปไม่ต่อกัน มีเพลงโผล่มาทั้งที่สั่งห้าม | โมเดลเจนเสียงของแต่ละคลิป**แยกกันโดยสิ้นเชิง** ไม่รู้ว่ามีคลิปก่อนหน้า | ตั้งค่า + ตัดต่อ |
| 2 | ทุกคนในเฟรมหน้าเหมือนกันหมด | identity bleed จาก character reference | การส่ง reference |
| 3 | ชุดทหารกลายเป็นเกราะแบบจีน | ไม่มี costume sheet + ใช้คำเรียกชาติแทนคำบรรยายรูปทรง | asset + prompt |
| 4 | SFX ไม่ตรงกับภาพ | เหมือนข้อ 1 + ตัด 5–6 จังหวะใน 15 วิ เร็วเกินกว่าเสียงจะตามทัน | ตั้งค่า + ตัดต่อ |
| 5 | ภาพยังเหมือนเกม/การ์ตูน | 5 สาเหตุซ้อนกัน ดู §13-5 | ทุกขั้น |

### 13-1 · เสียงไม่ต่อเนื่อง และมีเพลงโผล่มา

**สาเหตุ:** native audio ถูกเจนต่อคลิป โดยไม่มีบริบทของคลิปข้างเคียง **ความต่อเนื่องจึงเป็นไปไม่ได้เชิงโครงสร้าง**
ไม่ใช่ prompt ไม่ดี และคำสั่ง `no music` ก็ไม่ผูกมัดโมเดล มันเป็นแค่น้ำหนัก ไม่ใช่กฎ

**แก้:**
1. ตั้ง `generate_audio: false` ทุกคลิป — **ราคาเท่าเดิม ไม่มีอะไรเสีย** (§3)
2. ทำเสียงบรรยากาศ **เส้นเดียวยาวตลอดทั้งตอน** ในโปรแกรมตัดต่อ แล้ววาง spot SFX ทับตามจังหวะภาพ
3. ลบบรรทัด `AUDIO:` ออกจาก prompt ตาม §6.4

> ถ้ายังอยากได้เสียงจากโมเดลไว้เป็นตัวอ้างอิง ให้เจนแยกไว้ฟังเฉย ๆ **อย่าเอาเข้าไฟล์ตัดต่อ**

### 13-2 · ทุกคนหน้าเหมือน character reference (identity bleed)

**สาเหตุ:** เมื่อส่ง character sheet เข้า `image_references` โมเดลเข้าใจว่า **"นี่คือหน้าของคนในคลิปนี้"**
ไม่ใช่ "นี่คือหน้าของคนคนหนึ่ง" พอมีมนุษย์หลายคนในเฟรม มันจึงแจกหน้าเดียวกันให้ทุกคน
ยิ่งส่ง reference น้อยชนิด ยิ่งเบลอหนัก

**แก้ — เรียงตามลำดับที่ควรลองก่อนหลัง:**
1. **ช็อตที่มีคนหลายคน: ไม่ต้องส่ง character sheet เลย** ส่งแค่ `LOC` + `crowd sheet` แล้วบรรยายตัวเอกด้วยคำ
2. **แยกช็อตให้ชัด** ช็อตพระเอก = ส่ง `CH-01` · ช็อตฝูงชน = ไม่ส่ง · ช็อตที่มีทั้งคู่ = จัดให้คนอื่นเป็นเงา หันหลัง หรือหลุดโฟกัส
3. **ทำ crowd sheet** — ภาพเดียวที่มีคน 5–8 คน หน้าตา อายุ รูปร่างต่างกันชัด ส่งเข้าไปคู่กับ `CH-01`
   ให้โมเดลมีหน้ามากกว่าหนึ่งแบบให้เลือก
4. **เขียนกันไว้ในบรรทัด ELEMENTS ทุกครั้งที่มีคนเกินหนึ่ง:**
   ```
   only CH-01 has the referenced face; every other person is a different
   individual with a different face, age, build and hair — background people
   must not resemble the reference
   ```
5. ตัวละครที่มีชื่อทุกตัว **ต้องมี sheet ของตัวเอง** อย่าให้ตัวเอกเป็น reference เดียวทั้งเรื่อง

### 13-3 · เครื่องแต่งกายกลายเป็นของอีกชาติ

**สาเหตุ:** คำว่า `Burmese` `Siamese` `Ayutthaya` มีตัวอย่างในชุดข้อมูลน้อยมาก เมื่อโมเดลไม่มีของจริงจะอ้างอิง
มันจะถอยไปหา **ค่ากลางของ "ทหารเอเชียโบราณ" ซึ่งคือจีน** (เกราะเกล็ด บ่าตั้ง หมวกทรงกรวย)
ซ้ำร้าย ไม่มี costume sheet อยู่ในสายอ้างอิงเลย — มันจึงไม่มีอะไรให้ยึด

**แก้:**
1. **ทำ costume sheet เป็นภาพจริง** (ฟรี) แล้วส่งเข้า `image_references` ทุกคลิปที่มีกลุ่มนั้น
   ทำเป็น sheet เต็มตัวหน้า-หลัง คนเดียว พื้นขาว เหมือน character sheet
2. **เลิกเรียกด้วยชื่อชาติ บรรยายด้วยรูปทรงและวัสดุแทน** เช่น
   ```
   bare-chested or wearing a short unlined cotton jacket, a length of cloth
   wrapped and tucked at the waist reaching mid-calf, bare legs below the knee,
   bare feet or simple leather sandals, a cloth turban wrapped low on the head,
   a plain lacquered shield and a single-edged blade, no metal body armour
   ```
3. **ใส่ negative ตรง ๆ ในบรรทัด ELEMENTS:**
   ```
   not in frame: Chinese armour, lamellar or scale plate, shoulder pauldrons,
   conical metal helmets, wuxia costume, Ming or Qing dynasty dress, samurai
   armour, Japanese elements, Korean hanbok, any full-body metal armour
   ```
4. ถ้ายังหลุด ให้ **ล็อกด้วยคีย์เฟรม** — เจนภาพนิ่งที่ชุดถูกต้องก่อน แล้วส่งเป็น `start_image`
   วิดีโอจะตามภาพเปิดเสมอ

### 13-4 · SFX ไม่ตรงกับภาพ

**สาเหตุ:** เหมือน §13-1 บวกกับปัญหาโครงสร้าง — คลิป 15 วิที่มี 5–6 จังหวะตัด
คือ **เสียงต้องเปลี่ยนทุก 2.5 วินาที** ซึ่ง native audio ทำไม่ได้ มันเจนเป็นก้อนเดียวจบ

**แก้:**
1. ปิดเสียงโมเดล แล้ว **เปลี่ยนหน้าที่ของบรรทัด `SFX:` ใน prompt** จาก "คำสั่งให้โมเดล"
   เป็น **"ใบสั่งงานให้คนตัดต่อ"** — เก็บไว้ในสคริปต์ ไม่ต้องส่งเข้าโมเดล
2. เขียนใหม่เป็นรายการที่มี timecode จริง เพราะตอนนี้คุณมีภาพแล้ว รู้แล้วว่าอะไรอยู่วินาทีไหน
   ```
   SFX (post) — EP1 CLIP2
   00:00.0  ผ้าเสียดสี, เบา
   00:02.4  เท้าเหยียบดินแห้ง ×2
   00:05.8  ศอกผ่าอากาศ (ตรงรอยตัด SHOT C)
   00:09.1  หายใจออกทางจมูก
   00:12.0  เงียบสนิทถึงจบ ยกเว้น room tone
   ```
3. ถ้ายืนยันจะใช้ native audio จริง ๆ ให้ **ลดเหลือ 2–3 จังหวะต่อคลิป** เสียงถึงจะตามทัน
   แต่จะแลกกับความเร็วของการตัดที่หายไป — งานละครสั้นไม่คุ้ม

### 13-5 · ภาพยังเหมือนเกม ไม่เหมือนหนัง

**นี่คือข้อที่มีหลายสาเหตุซ้อนกัน แก้ทีละข้อไม่พอ ต้องแก้พร้อมกัน**

| สาเหตุ | ทำไมถึงทำให้เป็นเกม | แก้ |
|---|---|---|
| **ก. `mode: fast`** | โหมดเร็วลดขั้นตอนคำนวณ ผลคือพื้นผิวเรียบและแสงง่าย = หน้าตาเกม | ใช้ `mode: std` |
| **ข. คีย์เฟรมเป็น CG อยู่แล้ว** | **วิดีโอสืบทอดสไตล์จากภาพเปิดเสมอ** ถ้าภาพนิ่งดูเป็นเกม คลิปจะเป็นเกม 100% | เจนคีย์เฟรมใหม่ด้วย prompt สายภาพถ่าย ตรวจให้ผ่านก่อนค่อยไปต่อ |
| **ค. คำว่า `cinematic` และพวกพ้อง** | ในชุดข้อมูล คำพวกนี้ติดมากับภาพ CG ภาพเกม และ concept art ไม่ใช่ฟุตเทจจริง | ลบทิ้งทั้งหมด ดูรายการคำต้องห้ามใน §6.4 |
| **ง. ไม่ได้บรรยายพฤติกรรมของกล้องจริง** | บอกชื่อรุ่นกล้องไม่ได้ผล โมเดลไม่รู้จัก "Alexa 35" ในเชิงภาพ แต่รู้จัก motion blur, focus falloff, sensor noise | ใช้ BASE LOOK เวอร์ชัน live-action §6.4 |
| **จ. ไม่มี negative กันภาพ CG** | ไม่บอกว่าไม่เอาอะไร มันก็ให้ค่ากลาง ซึ่งค่ากลางของ AI คือภาพสวยเนียนแบบ 3D | ใส่ท่อน `NOT:` ทั้งท่อนจาก §6.4 |
| **ฉ. bitrate ต่ำ** | การบีบอัดกลืนเกรนและรายละเอียดผิว เหลือแต่พื้นผิวเรียบ = พลาสติก | `bitrate_mode: high` |

**ผลต่อค่าใช้จ่าย:** `fast → std` ที่ 15 วิ = 52.5 → 67.5 เครดิต/คลิป (**+15/คลิป, +60/ตอน**)
งานสมจริงจ่ายส่วนนี้คุ้ม งานสไตไลซ์ไม่ต้องจ่าย

### 13-8 · เจอข้อจำกัดกลางทางที่ไม่มีในเอกสาร

**`soul_2` รับ `medias` ได้ใบเดียว** (`max: 1`) — ใช้ทำ character sheet ได้ดีและถูกที่สุด
แต่ทำคีย์เฟรมที่ต้องอ้างอิงหลายใบพร้อมกัน (สถานที่ + ชุด + ฝูงชน) **ไม่ได้**
งานที่ต้อง reference หลายใบให้ไปใช้ `seedream_v4_5` / `seedream_v5_pro` / `flux_2` / `nano_banana_2`
ซึ่งรับ `image_references` ได้หลายใบ

**บทเรียนทั่วไป:** ก่อนวางไปป์ไลน์ที่พึ่ง reference หลายใบ **เช็ค `medias[].max` ของโมเดลนั้นก่อน**
ด้วย `models_explore action:"get"` ไม่งั้นจะไปเจอตอนกลางทางแล้วต้องรื้อ

### 13-7 · ภาพถูกทุกอย่างแต่คนดูไม่รู้สึกอะไร

**สาเหตุ:** prompt สั่งได้แต่ว่ามีอะไรอยู่ในเฟรม ไม่ได้สั่งว่าคนดูควรรู้สึกยังไง
ภาพที่ถูกต้องทุกข้อแต่ไม่มีใครทำอะไรกับใคร คือภาพนิ่งที่ขยับได้ ไม่ใช่หนัง

**แก้:** เพิ่มบรรทัด `EMOTION:` เข้าไปใน prompt ตาม **§14** — และ **§14 คือหมวดที่ต้องอ่านก่อนเขียน
ตัวร้าย** เพราะความเกลียดเป็นสิ่งที่ต้องออกแบบ ไม่ใช่สิ่งที่เกิดเองจากการใส่คนถือดาบเข้าไปในเฟรม

### 13-6 · กฎที่ได้จากรอบนี้ — ห้ามลืม

1. **ห้ามยิงทั้งตอนด้วย prompt ที่ยังไม่เคยผ่านตา** ยิง **1 คลิป** ด้วยชุดใหม่ ดูก่อน ผ่านแล้วค่อยยิงที่เหลือ
   รอบนี้เสียไป 4 คลิปเพราะยิงยกตอน — ที่ `std` คือ 270 เครดิต
2. **ปัญหาสไตล์ให้แก้ที่ภาพนิ่งก่อนเสมอ** ภาพนิ่งฟรี วิดีโอไม่ฟรี ถ้าภาพนิ่งยังไม่เหมือนหนัง วิดีโอไม่มีทางเหมือน
3. **reference ที่ไม่ได้ตั้งใจส่ง คือ reference ที่ทำงานผิด** ทุกครั้งที่ใส่ `image_references` ให้ถามว่า
   "ถ้าโมเดลเอาอันนี้ไปใช้กับ**ทุกอย่าง**ในเฟรม จะพังไหม"
4. **ชื่อ (ชาติ ยุค รุ่นกล้อง) ไม่ทำงาน คำบรรยายรูปทรงและพฤติกรรมทำงาน** ใช้กับทั้งชุด ทั้งกล้อง ทั้งสถานที่

## 14. อารมณ์ใน prompt — วิธีสร้างตัวร้ายที่คนดูเกลียดจริง

### 14.1 กฎข้อเดียวที่ต้องเข้าใจก่อน

**โมเดลเรนเดอร์ "พฤติกรรม" ไม่ได้เรนเดอร์ "ความรู้สึก"**
เขียนว่า `an evil cruel villain, the audience should hate him` ได้ผลเป็นศูนย์ — มันไม่ใช่ภาพ
ทุกอารมณ์ต้องถูกแปลงเป็น **การกระทำที่ถ่ายติด**

| เขียนแบบนี้ (ไร้ผล) | เขียนแบบนี้ (ได้ผล) |
|---|---|
| `cruel and evil` | `he presses his heel down on a fallen man's hand and leaves it there` |
| `he enjoys the suffering` | `he yawns while it happens, looking somewhere else` |
| `terrifying presence` | `everyone else is moving fast; he is the only one moving slowly` |
| `the crowd is desperate` | `a woman reaches for a dropped bundle and is pulled away before she touches it` |

### 14.2 เครื่องยนต์ความเกลียด — 7 ตัว ใช้ 3–4 ตัวต่อคลิปพอ

| # | กลไก | ทำไมได้ผล | เขียนใน prompt ว่ายังไง |
|---|---|---|---|
| 1 | **ความโหดที่ไม่จำเป็น** | ความรุนแรงที่จำเป็นอ่านว่า "หน้าที่" · ที่ไม่จำเป็นอ่านว่า "นิสัย" | `the captive is already bound and compliant; he strikes him anyway` |
| 2 | **ความเบื่อ ไม่ใช่ความสะใจ** | คนโหดที่สนุกยังเป็นมนุษย์ · คนโหดที่เบื่อแปลว่าเหยื่อไม่ใช่คนสำหรับเขา | `he does it without looking, mid-conversation with someone off-frame` |
| 3 | **ไม่มีความเสี่ยงเลย** | ความเกลียดต้องการความไม่เท่าเทียม ถ้าเหยื่อสู้ได้ มันกลายเป็นการต่อสู้ | `he is armed and dry and rested; they are roped, barefoot and soaked` |
| 4 | **เหยื่อหนึ่งคน ไม่ใช่ฝูงชน** | ฝูงชนที่ทุกข์คือสถิติ · หน้าหนึ่งหน้าที่คนดูจำได้คือเรื่อง | `one specific old man, shown clearly before it happens to him` |
| 5 | **พรากของเล็ก ๆ ที่มีความหมาย** | คนดูรู้สึกกับของที่จับต้องได้มากกว่ากับคำว่าอิสรภาพ | `he takes the small cloth bundle from her hands and drops it in the mud` |
| 6 | **เขาสบาย ในขณะที่ทุกคนไม่** | ความต่างที่เห็นได้ในเฟรมเดียว แรงกว่าคำอธิบายทั้งฉาก | `he eats while they watch` · `he is under shelter while they stand in rain` |
| 7 | **ไม่มีใครลงโทษเขาในคลิปนี้** | ความเกลียดคือหนี้ที่คนดูอยากให้ชำระ **ชำระเร็ว = ความเกลียดหายทันที** | `no one stops him; the shot ends with him unharmed and unbothered` |

**ตัวคูณ:** ให้พระเอกอยู่ในเฟรมและ**เห็นทุกอย่างแต่ทำอะไรไม่ได้**
`the fighter watches from the line, jaw locked, hands bound, and does nothing`
ความไร้อำนาจของคนดูถูกส่งผ่านตัวละคร — นี่คือสิ่งที่ทำให้คนอยากดูตอนต่อไป

### 14.3 สิ่งที่ไม่ทำให้เกลียด — เลิกใช้

- **หน้าโหด แผลเป็น ผ้าปิดตา ฟันเหลือง** — นี่คือเครื่องแต่งกาย ไม่ใช่นิสัย คนดูอ่านออกว่ากำลังถูกสั่งให้เกลียด
- **หัวเราะแบบวายร้าย** — ใช้ไม่ได้อยู่แล้วเพราะห้ามตัวละครขยับปาก และมันเชย
- **ตัวร้ายที่แข็งแกร่งน่าเกรงขาม** — นั่นคือความน่าเกรงขาม ไม่ใช่ความเกลียด สองอย่างนี้คนละอารมณ์
- **ความรุนแรงเยอะขึ้นเรื่อย ๆ** — คนดูชาเร็วมาก ความโหดครั้งเดียวที่เจาะจง แรงกว่าสิบครั้งที่กว้าง ๆ
- **ตัวร้ายที่ถูกลงโทษในคลิปเดียวกัน** — ปิดหนี้เร็วเกินไป คนดูไม่เหลือเหตุผลจะดูต่อ

### 14.4 บรรทัดที่ต้องเพิ่มใน prompt

เพิ่ม `EMOTION:` เป็นบรรทัดที่ห้าของโครงใน §6.3 วางไว้หลัง `LIGHT:` ก่อน `SHOT A`

```
EMOTION: [คนดูควรรู้สึกอะไร — หนึ่งคำ] · [ใครทำอะไรกับใครถึงทำให้รู้สึกแบบนั้น
เป็นการกระทำที่ถ่ายติด] · [ตัวเอกอยู่ตรงไหนและทำอะไรไม่ได้] · [จบคลิปโดยยังไม่มี
ใครชำระหนี้นี้]
```

**ตัวร้ายต้องมีรหัส element ของตัวเอง** เช่น `AN-01` (antagonist) และต้องมี **character sheet
เหมือนตัวเอก** — ถ้าตัวร้ายหน้าเปลี่ยนทุกตอน คนดูเกลียดใครไม่ถูก และความเกลียดจะไม่สะสม

### 14.5 ข้อบังคับ — ตัวร้ายคือคน ไม่ใช่ชาติ

งานประวัติศาสตร์ที่คู่ขัดแย้งเป็นชาติที่ยังมีอยู่จริงในปัจจุบัน **ต้องผูกความโหดไว้กับตัวบุคคลเสมอ**
ไม่ใช่กับกลุ่ม เชื้อชาติ หรือประเทศ

- ✗ `Burmese soldiers are cruel` — นี่คือการสร้างความเกลียดชังทางชาติพันธุ์ต่อคนที่มีชีวิตอยู่จริงวันนี้
- ✓ `AN-01, one named officer, does this specific thing` — เจาะจง จำได้ เกลียดได้
- **ใส่คนของฝ่ายเดียวกับตัวร้ายที่ไม่โหดอย่างน้อยหนึ่งคน** ในซีรีส์ — ทหารที่ลังเล ที่หันหน้าหนี
  ที่แอบให้น้ำ นอกจากป้องกันการเหมารวมแล้ว **มันทำให้ตัวร้ายดูแย่ลงด้วย** เพราะพิสูจน์ว่าเขาเลือกเอง
- ในแคปชั่นและชื่อคลิป **ห้ามใช้ถ้อยคำที่ชวนเกลียดคนทั้งชาติ** เล่าเรื่องของคนคนหนึ่ง

กฎนี้ไม่ได้ทำให้ดราม่าอ่อนลง มันทำให้แรงขึ้น — คนดูเกลียดใบหน้าที่จำได้ ไม่เกลียดคำนามรวม

### 14.6 ก่อน / หลัง

**ก่อน** — ถูกทุกอย่าง ไม่มีใครรู้สึกอะไร
```
SHOT B (3-6s) MEDIUM: an armed man shoves a captive into line with his shield.
```

**หลัง** — ใช้กลไก 1, 2, 4, 6, 7 พร้อมกัน
```
EMOTION: the viewer should hate AN-01 specifically · he takes a small cloth
bundle from an old man who is already roped and compliant, looks at it without
interest, and drops it face-down in the mud while turning away to speak to
someone off-frame · the fighter is third in the line, watching, wrists bound,
and does nothing · no one stops AN-01 and the shot ends with him dry and
unbothered

SHOT B (3-6s) MEDIUM: AN-01, dry under an oiled cloth cape, takes the bundle
  from the old man's bound hands without looking at him, and lets it fall into
  the mud as he turns away mid-sentence to someone off-frame.
SHOT C (6-9s) CU: the old man's face as he watches it sink, rain on his cheeks,
  mouth closed, making no sound.
```
ต่างกันที่ไหน: มีเหยื่อที่มีหน้า · มีของที่มีความหมาย · ความโหดไม่จำเป็นเลย ·
ตัวร้ายไม่สนใจด้วยซ้ำ · เขาแห้ง เหยื่อเปียก · และไม่มีใครลงโทษเขา
