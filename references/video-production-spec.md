# VIDEO PRODUCTION SPEC — กรอกข้างบน แล้วอ่านลงมา

ไฟล์เดียวจบสำหรับงานวิดีโอ AI: **แก้เฉพาะบล็อก SETTINGS** ที่หัวไฟล์ ทุกอย่างใต้เส้นคำนวณจากค่านั้น
บอกว่าต้องเจนอะไร กี่ชิ้น ด้วยโมเดลไหน ฟรีหรือเสียเงิน และส่ง request หน้าตายังไง

> ราคาทุกตัวในไฟล์นี้ **วัดจริงด้วย `get_cost` เมื่อ 2026-08-04 บนแพลน Plus**
> ราคาเปลี่ยนได้ — ก่อนเริ่มงานใหญ่ให้ยิง `get_cost: true` หนึ่งครั้งเพื่อยืนยัน อย่าเชื่อไฟล์นี้อย่างเดียว

---

## 1. SETTINGS — แก้แค่ตรงนี้

```yaml
# --- เรื่อง ---
title:            "นายขนมต้ม"          # ชื่อเรื่อง/โปรเจกต์
topic:            "เชลยศึกสยามที่ถูกสั่งให้ขึ้นชกในงานสมโภชของราชสำนักพม่า"
language:         th                     # ภาษาพากย์และซับ
genre:            short-drama            # short-drama | documentary | explainer | story

# --- ขนาดงาน ---
ep_count:         10                     # จำนวนตอน (1 = คลิปเดี่ยว)
ep_minutes:       1                      # ความยาวต่อตอน (นาที)
clip_seconds:     15                     # ความยาวต่อคลิปที่โมเดลเจนได้

# --- สเปกภาพ ---
aspect:           "9:16"                 # 9:16 แนวตั้ง | 16:9 แนวนอน
resolution:       "720p"
video_model:      seedance_2_0           # ดูตาราง §3
video_mode:       fast                   # std | fast | mini
look:             "photoreal cinematic, ARRI Alexa Mini + Master Prime"

# --- เสียง ---
native_audio:     true                   # true = ให้โมเดลใส่ SFX มาด้วย
music:            false                  # false = ห้ามมีดนตรี (ต้องเขียนย้ำใน prompt)
vo_engine:        elevenlabs             # elevenlabs (นอกระบบ) | seed_audio (ในระบบ)
subtitles:        true

# --- นักแสดง/สถานที่ ---
characters:       2                      # ตัวละครที่ต้องหน้าเหมือนกันทุกตอน
locations:        4                      # ฉากหลักที่ใช้ซ้ำ

# --- งบ ---
credits_on_hand:  781.5
```

## 2. ตัวเลขที่คำนวณได้ทันที

| ค่า | สูตร | ตัวอย่างจาก SETTINGS ข้างบน |
|---|---|---|
| ความยาวรวม | `ep_count × ep_minutes × 60` | 600 วินาที (10 นาที) |
| คลิปต่อตอน | `ceil(ep_minutes × 60 ÷ clip_seconds)` | 4 |
| **คลิปทั้งหมด** | `ep_count × คลิปต่อตอน` | **40** |
| บรรทัดพากย์ | `= คลิปทั้งหมด` (1 บรรทัด/คลิป) | 40 |
| คีย์เฟรม | `= คลิปทั้งหมด` | 40 |
| Character sheet | `= characters` | 2 |
| Location sheet | `= locations` | 4 |
| **ภาพที่ต้องเจนรวม** | `คีย์เฟรม + characters + locations` | **46** |
| เครดิตค่าคลิป | `คลิปทั้งหมด × clip_seconds × อัตรา/วินาที (§3)` | 40 × 15 × 3.5 = **2,100** |
| เครดิตค่าภาพ | `ภาพรวม × 0.12` (soul_2) | ~5.5 |
| **ทำได้กี่คลิปด้วยเครดิตที่มี** | `floor(credits_on_hand ÷ ราคา/คลิป)` | 781.5 ÷ 52.5 = **14 คลิป (3.5 ตอน)** |
| **ทำได้กี่ตอนเต็ม** | `floor(ข้างบน ÷ คลิปต่อตอน)` | **3 ตอน** |

> ถ้าเครดิตไม่พอทั้งซีรีส์ **ให้ทำทีละตอนจนจบตอน** อย่าเจนครึ่ง ๆ กลาง ๆ ทุกตอน
> ตอนที่ไม่ครบทุกคลิปคือตอนที่ปล่อยไม่ได้ = เครดิตที่จ่ายไปเปล่า

## 5. Request ที่ต้องส่ง

### 5.1 พรีเช็คราคา (ทำก่อนเสมอ — ไม่ส่งงาน ไม่หักเครดิต)
```json
{ "params": { "model": "seedance_2_0", "prompt": "cost probe", "duration": 15,
  "resolution": "720p", "mode": "fast", "aspect_ratio": "9:16", "get_cost": true } }
```

### 5.2 Character sheet (ฟรี)
```json
{ "params": { "model": "soul_2", "aspect_ratio": "16:9", "quality": "2k",
  "prompt": "<§6.1>" } }
```

### 5.3 คีย์เฟรม (ฟรี) — แนบ sheet เป็น reference
```json
{ "params": { "model": "soul_2", "aspect_ratio": "9:16",
  "prompt": "<ช็อตแรกของคลิปนั้น> <§6.4 BASE LOOK>",
  "medias": [ { "role": "image", "value": "<character_sheet_job_id>" } ] } }
```

### 5.4 คลิป (เสียเงิน) — ยิงทีละชุดไม่เกิน 12
```json
{ "requests": [ { "index": 1, "params": {
  "model": "seedance_2_0", "mode": "fast", "duration": 15,
  "resolution": "720p", "aspect_ratio": "9:16",
  "generate_audio": true, "genre": "drama",
  "prompt": "<§6.3 จังหวะตัด> <§6.4 BASE LOOK>",
  "medias": [
    { "role": "start_image",      "value": "<keyframe_job_id>" },
    { "role": "image_references", "value": "<character_sheet_job_id>" },
    { "role": "image_references", "value": "<location_sheet_job_id>" } ] } } ] }
```
เครื่องมือ: `generate_video_batch` → `jobs_wait` (ทีละ ≤12) → `show_generation_by_ids` ครั้งเดียว

### 5.5 ขอใช้โควต้าฟรี
เติม `"use_unlim": true` ในทุก request ของรอบนั้น **ส่งไปเลย อย่าไปเช็คก่อนว่ามีสิทธิ์ไหม** —
ระบบตอบกลับเป็น error ที่อ่านออก ไม่หักเงินเงียบ ๆ

| error ที่ได้ | แปลว่า | ทำยังไงต่อ |
|---|---|---|
| `unlim_trial_available` | มีสิทธิ์ แต่ยังไม่เปิด | เรียก `show_plans_and_credits` แล้วรอผู้ใช้ |
| `unlim_trial_expired` / `unlim_not_eligible` | สิทธิ์หมด/ไม่มี | **หยุด ถามก่อน** ว่าจะจ่ายเครดิตต่อไหม |
| `unlim_not_supported` | โมเดลนี้ไม่มีทางฟรี | เปลี่ยนโมเดลหรือยอมจ่าย |
| `unlim_config_not_covered` | โมเดลฟรี แต่ค่าที่ตั้งไม่อยู่ในสิทธิ์ | ลดความยาว/ความละเอียดให้เข้ากรอบ |

## 6. เทมเพลต prompt

### 6.1 Character sheet
```
Split-screen character sheet composition, left side a full-body shot standing
upright facing camera, both feet flat, arms relaxed, full head-to-toe framing,
right side a tight chest-up portrait of the same character, identical original
character on both sides, single subject only exactly one person, pure white
seamless studio background,
[อายุ + ผิว], [รูปหน้า ขากรรไกร โหนกแก้ม จมูก ปาก], [ตา + naturally muted
catchlights, no artificial glare], [คิ้ว], [ผม: สี ความยาว ทรง ความมัน],
visible fine skin texture with natural pores, uneven tone, old scars, calloused
hands, slight natural sweat sheen, no digital smoothing, no beauty filter,
no AI-airbrushed look,
[รูปร่าง], wearing [บนล่างครบ: เสื้อ → ชั้นนอก → ท่อนล่าง → คาดเอว → รองเท้า →
เครื่องประดับ], natural anatomy, unretouched documentary photography style,
soft diffused studio lighting, cinematic realism, 4K, sharp focus on skin texture,
single subject only, no other people, no duplicate figures, no mannequin, no props,
no furniture, left panel standing full-body not cropped not sitting, right panel
tight close-up not full body, no babyface, original character not resembling any
real person, no text, no watermark, no logos, no frame borders.
```
**กติกา:** ตัวละครต้องเป็นตัวละครออริจินัลเสมอ · ห้ามอ้างอิงหน้าคนจริงหรือ IP ที่มีลิขสิทธิ์ ·
ตัวละครผู้ใหญ่ต้องระบุโครงหน้าผู้ใหญ่ ไม่งั้นโมเดลจะออกมาหน้าเด็ก ·
แก้ครั้งต่อไปต้องเขียนรายละเอียดเดิมซ้ำทั้งหมด เปลี่ยนเฉพาะสิ่งที่ตั้งใจเปลี่ยน

### 6.2 Location sheet
```
[สถานที่ + ยุคสมัย + เวลาของวัน + สภาพอากาศ], [วัสดุและรายละเอียดที่มองเห็น],
[ทิศทางแสง], empty of people, wide establishing frame.
+ §6.4 BASE LOOK
```

### 6.3 คลิป — จังหวะตัด + ELEMENTS + SFX ต้องอยู่ **ใน prompt** ทั้งหมด

อย่าเก็บ element กับ SFX ไว้แค่ในเอกสารข้างนอก **เขียนลงไปใน prompt ที่ส่งให้โมเดลจริง ๆ**
โมเดลอ่านมันแล้วใช้จัดฉาก จัดเสียง และรักษาความต่อเนื่องให้ ถ้าไม่เขียน มันจะเดาเอง

```
ELEMENTS: [LOC-## ชื่อสถานที่ + เวลาของวัน + อากาศ] | [CH-## ตัวละคร +
สภาพ WD-## ณ คลิปนี้] | [PR-## พร็อพที่ต้องเห็นในเฟรม] | [สิ่งที่ห้ามมีในเฟรม]
CAMERA: [เลนส์] [การเคลื่อนกล้อง] [ไล่ขนาดภาพ]
LIGHT: [แหล่งแสง] [ทิศทาง] [มี/ไม่มีแสงเติม]

SHOT A (0-2s)  [ขนาดภาพ] [มุม]: [สิ่งที่เกิดขึ้น]
SHOT B (2-5s)  [ขนาดภาพ] [มุม]: [สิ่งที่เกิดขึ้น]
SHOT C (5-8s)  ...
SHOT D (8-11s) ...
SHOT E (11-15s)...

SFX: [ชั้นตัวละคร: หายใจ ฝีเท้า ผ้า เสียงพยายาม] + [ชั้นสภาพแวดล้อม: ลม ไฟ
ฝูงชน น้ำ room tone] + [ชั้นเน้นจังหวะ: กระแทก ของตก โลหะ หรือความเงียบ]
พร้อมบอกว่าเสียงไหนอยู่ช็อตไหน — เช่น "impact on SHOT C, silence over SHOT E"
+ §6.4 BASE LOOK
```

**ตัวอย่างที่กรอกแล้ว (คลิป 15 วิ 9:16)**
```
ELEMENTS: LOC-02 prisoner compound at night, no wind, packed dirt |
CH-01 the fighter, WD-02 state: dusty loincloth, no facial wounds yet |
PR-03 hemp rope hand-wraps, PR-05 a dying cooking fire |
nothing modern in frame, no other people visible

CAMERA: 35mm, light handheld, ECU -> MEDIUM -> WIDE progression
LIGHT: single low side firelight, no fill, background falls to pure black

SHOT A (0-3s) ECU: a rope wrap tightening around a fist, fibres catching.
SHOT B (3-6s) LOW ANGLE: bare feet settling into a fighting stance on dirt.
SHOT C (6-9s) MEDIUM SILHOUETTE: a slow controlled knee and elbow sequence,
  no opponent, mouth closed, characters do not speak.
SHOT D (9-12s) MACRO: sweat running down a scarred forearm in firelight.
SHOT E (12-15s) WIDE: him alone in the centre of the empty compound, motion
  starts on frame one and never stops.

SFX: steady controlled breathing through the nose and rope fibres creaking
(character layer) + faint fire crackle and distant night insects (ambient
layer) + one sharp cloth snap on the elbow at SHOT C, then near-silence with
only breath over SHOT E (accent layer). No music, no melody, no drums.
```

**กติกา:**
- **ทุก prompt ต้องมีบรรทัด `ELEMENTS` `CAMERA` `LIGHT` `SFX` ครบสี่บรรทัด** ช่องที่ไม่มีให้เขียน `none` ห้ามลบบรรทัดทิ้ง
- **`ELEMENTS` ต้องมีท่อน "สิ่งที่ห้ามมีในเฟรม" เสมอ** — นี่คือท่อนที่กันของสมัยใหม่ ตัวประกอบที่ไม่ได้เรียก และตัวหนังสือ
- **`SFX` ต้องครบ 3 ชั้น และต้องผูกกับช็อต** เขียนแค่รายชื่อเสียงลอย ๆ โมเดลจะเกลี่ยเท่ากันหมดจนไม่มีจังหวะ
- **ความเงียบสั่งได้และควรสั่ง** — `near-silence over SHOT E` ให้ผลแรงกว่าเสียงดังในคลิปสั้น
- **`WD` ในบรรทัด ELEMENTS ต้องตรงกับสภาพสะสม ณ คลิปนั้น** ดูกติกา §7.3
- คลิป 15 วิ = 5–6 จังหวะ · **ห้ามช็อตไหนยาวเกิน 3 วินาที** ไม่งั้นได้สไลด์โชว์
- **นับรอยตัดที่ได้กลับมาจริง** ถ้าน้อยกว่าที่สั่ง ยิงซ้ำโดยเขียนช่วงเวลาย้ำอีกรอบ ครั้งเดียว
  ถ้ารอบสองยังไม่ได้ ปล่อยผ่าน แล้วจดว่าคลิปไหนช้า
- **เปลี่ยนขนาดภาพและมุมทุกจังหวะ** (WIDE / MEDIUM / CU / ECU / low / high / overhead)
- **ห้ามเปิดทุกคลิปด้วย establishing wide เหมือนกัน**
- **ห้ามใช้ OTS กับช็อตที่ไม่มีคนอยู่ในเฟรม** โมเดลจะสร้างคนขึ้นมาเอง
- **ตัวละครห้ามขยับปากพูด** ถ้าใช้พากย์แยก → เขียน `characters do not speak, mouths closed`
- ต้องมีการเคลื่อนไหวตั้งแต่เฟรมแรก → เขียน `motion starts on frame one`

### 6.4 BASE LOOK — ต่อท้ายทุก prompt ห้ามแก้ระหว่างเรื่อง
```
[LOOK จาก SETTINGS], filmic latitude, gentle highlight rolloff, fine organic grain,
shallow depth of field. Lighting is practical only. Palette [ระบุ 3–4 สี], no
teal-orange grade. [ยุคสมัย/โลกของเรื่อง], no modern objects, no printed text in
frame. Faces stay identical to the character reference.
No on-screen text, no subtitles, no watermark, no logo.
AUDIO: diegetic sound effects only — no music, no score, no singing, no spoken
dialogue, no voiceover.
```
> ถ้ามีดนตรีหลุดมา เติมท้าย: `absolutely no musical instruments, no drums, no melody, room tone only`
> ยังหลุดอีก → `generate_audio: false` แล้วใส่ SFX เองตอนตัดต่อ

## 7. ELEMENT — สิ่งที่สคริปต์ต้องกำกับทุกบรรทัด

สคริปต์ที่มีแต่คำพูดคือสคริปต์ที่ยังทำไม่ได้ **ทุกคลิปต้องประกาศ element ให้ครบ**
ไม่งั้นโมเดลจะคิดเอง แล้วเรื่องจะหลุดตั้งแต่คลิปที่สาม

### 7.1 ทะเบียน element

| รหัส | คืออะไร | ต้องทำ sheet ก่อนไหม |
|---|---|---|
| `CH-##` | ตัวละคร | **ต้อง** ทุกตัวที่โผล่เกิน 1 คลิป |
| `LOC-##` | สถานที่ | **ต้อง** ทุกที่ที่ใช้ซ้ำ |
| `PR-##` | พร็อพ / วัตถุที่มีบทบาท | ต้อง ถ้าโผล่ ≥ 2 คลิป · โผล่ครั้งเดียวบรรยายใน prompt ได้เลย |
| `WD-##` | เครื่องแต่งกาย + **สภาพความเสียหาย** | ไม่ต้องทำแยก แต่ต้องประกาศทุกคลิป |
| `CAM-##` | เลนส์ · การเคลื่อนกล้อง · ไล่ขนาดภาพ | ไม่ต้อง |
| `LGT-##` | ทิศทางและแหล่งแสง | ไม่ต้อง |
| `SFX-##` | เสียงเอฟเฟกต์ | ไม่ต้อง แต่ต้องมีรายการ |
| `VO-##` | บรรทัดพากย์ | ไม่ต้อง |

**จำนวน sheet ที่ต้องเจน** = `characters + locations + พร็อพที่โผล่ ≥ 2 คลิป`

### 7.2 หน้าตาบรรทัดสคริปต์ที่ใช้ได้จริง

ทุกคลิปเขียนแบบนี้ **ครบทั้ง 8 ช่อง ช่องที่ไม่มีให้ใส่ `—` ห้ามเว้นว่าง**

```
[EP2 · CLIP 2 · 00:15–00:30]
VO-06 : "แต่ทุกคืนหลังไฟดับ เขาลุกขึ้นมาทำสิ่งเดียวที่ยังเป็นของเขาอยู่"
CH    : CH-01 นายขนมต้ม
WD    : WD-01 ผ้าเตี่ยวสภาพปกติ · ยังไม่มีบาดแผลบนใบหน้า
LOC    : LOC-02 ค่ายเชลย · กลางคืน · ไม่มีลม
PR    : PR-03 เชือกคาดมือ · PR-05 กองไฟที่กำลังจะดับ
CAM   : เลนส์ 35mm · แฮนด์เฮลด์เบา · ไล่ ECU → MEDIUM → WIDE
LGT   : กองไฟกองเดียว มาจากด้านข้างระดับต่ำ · ไม่มีแสงเติม · หลังดำสนิท
SFX   : SFX-04 ลมหายใจเป็นจังหวะ · SFX-07 เท้าบดดิน · SFX-02 ไฟแตกเบา
REF   : [LOC-02, CH-01, PR-03]
```

`REF` คือสิ่งที่ส่งเข้า `image_references` **เรียงตามลำดับนี้เสมอ: สถานที่ → ตัวละคร → พร็อพ**
สลับลำดับแล้วโมเดลจะให้น้ำหนักผิดตัว

**บรรทัดพวกนี้ไม่ได้อยู่แค่ในเอกสาร — มันแปลงตรงเข้า prompt** ตามตารางนี้:

| ช่องในสคริปต์ | ไปอยู่ตรงไหนของ prompt (§6.3) |
|---|---|
| `CH` + `WD` + `LOC` + `PR` | บรรทัด `ELEMENTS:` |
| `CAM` | บรรทัด `CAMERA:` |
| `LGT` | บรรทัด `LIGHT:` |
| `SFX` | บรรทัด `SFX:` **ต้องระบุด้วยว่าเสียงไหนอยู่ช็อตไหน** |
| `REF` | ฟิลด์ `medias[]` ของ request ไม่ใช่ตัว prompt |
| `VO` | ไม่เข้า prompt เลย ไปเข้า TTS อย่างเดียว |

ถ้าช่องไหนในสคริปต์ว่าง แปลว่า prompt จะขาดบรรทัดนั้น แล้วโมเดลจะเติมเอง — นั่นคือจุดที่เรื่องหลุด

### 7.3 กติกาความต่อเนื่อง — ข้อที่พังบ่อยที่สุด

- **`WD` เดินหน้าอย่างเดียว ห้ามถอยหลัง** บาดแผล เลือด ผ้าขาด ฝุ่น ที่เกิดในคลิปที่ 12 ต้องอยู่ในคลิปที่ 13 ถึงจบเรื่อง
  → เขียน state ไล่ไว้ล่วงหน้าทั้งเรื่อง เช่น `WD-01 สะอาด → WD-02 ฝุ่นจับ → WD-03 คิ้วแตก → WD-04 ตาซ้ายปิด`
- **`LOC` เดิมติดกันไม่เกิน 2 คลิป** แล้วต้องเปลี่ยนที่ หรืออย่างน้อยเปลี่ยนมุมและระยะ ไม่งั้นคนดูรู้สึกว่าเรื่องหยุดเดิน
- **`CH` ที่โผล่ครั้งแรกต้องมี sheet ก่อนเสมอ** ห้ามปล่อยให้โมเดลออกแบบหน้าคนใหม่กลางเรื่อง
- **`PR` ที่มีบทบาทต้องมีที่มาที่ไป** ของที่โผล่มาในมือโดยไม่เคยเห็นว่าได้มาจากไหน คือรอยรั่วที่คนดูจับได้
- **`SFX` ต้องมีอย่างน้อย 3 ชั้นต่อคลิป**: เสียงจากตัวละคร (หายใจ ฝีเท้า ผ้า) + เสียงสภาพแวดล้อม (ลม ไฟ ฝูงชน) + เสียงเน้นจังหวะ (กระแทก ของตก ความเงียบ)
  → **ความเงียบนับเป็น SFX** ใส่ `SFX-00 เงียบสนิท 2 วินาที` ได้ และมักได้ผลกว่าเสียงดัง
- **`CAM` ห้ามซ้ำสองคลิปติด** ถ้าคลิปก่อนเป็นแฮนด์เฮลด์ คลิปนี้เป็นล็อกช็อตหรือดอลลี่

### 7.4 element ที่ห้าม drift ทั้งเรื่อง

เขียนไว้ครั้งเดียวที่ §6.4 แล้ว **ห้ามแก้ระหว่างเรื่องเด็ดขาด**: BASE LOOK · พาเลตต์สี · หน้าตัวละคร ·
ยุคสมัยและวัตถุที่อนุญาตให้อยู่ในเฟรม · กติกาเสียง (มี/ไม่มีดนตรี)
ถ้าจำเป็นต้องแก้จริง ๆ ต้องเจนใหม่ทั้งตอน ไม่ใช่แก้เฉพาะคลิปเดียว

### 7.5 ตรวจก่อนส่งสคริปต์เข้าโปรดักชัน

- [ ] ทุกคลิปมีครบ 8 ช่อง ไม่มีช่องว่างเปล่า
- [ ] ทุก `CH` และ `LOC` ที่ปรากฏ มี sheet แล้ว
- [ ] `WD` ไล่ต่อเนื่องตั้งแต่คลิปแรกถึงคลิปสุดท้าย ไม่มีจุดที่ความเสียหายหายไป
- [ ] ไม่มี `LOC` เดียวกันติดกันเกิน 2 คลิป
- [ ] ทุกคลิปมี `SFX` ครบ 3 ชั้น
- [ ] `REF` เรียงสถานที่ → ตัวละคร → พร็อพ ทุกบรรทัด
- [ ] `PR` ทุกชิ้นมีที่มา ไม่มีของโผล่มาลอย ๆ

## 8. โครงเรื่อง — 6 ช่อง

ทุกงาน ทุกความยาว ต้องครบหกช่อง ความยาวเปลี่ยนขนาดช่อง ไม่เปลี่ยนจำนวนช่อง

| ช่อง | คืออะไร | ตกช่องนี้แล้วเป็นยังไง |
|---|---|---|
| 1 **ฐาน** | สภาพเดิม + ความเชื่อที่คนดูถืออยู่ | คนดูไม่รู้ว่าอะไรเปลี่ยน |
| 2 **สะดุด** | สิ่งที่ขัดกับความเชื่อนั้น | ไม่มีคนดู |
| 3 **ช่องว่าง** | คำถามที่ยังไม่ตอบ | คนดูไม่มีเหตุผลจะอยู่ต่อ |
| 4 **บีบ** | ลองแล้วไม่ได้ผล สถานการณ์แคบลง | กลายเป็นรายการสอนทำอาหาร |
| 5 **จ่าย** | ต้องเลือกสิ่งที่ไม่อยากเลือก | ตอนจบไม่มีใครเชื่อ |
| 6 **ลง** | สภาพใหม่ + สิ่งที่คนดูได้ติดตัว | จบแบบไม่รู้ว่าจบทำไม |

### วางหกช่องลงบนจำนวนตอน
| `ep_count` | การกระจาย |
|---|---|
| 1 | ทั้งหกช่องอยู่ในคลิปเดียว สะดุดต้องมาก่อนวินาทีที่ 3 |
| 3–5 | ตอน 1 = ฐาน+สะดุด+ช่องว่าง · ตอนกลาง = บีบ · ตอนสุดท้าย = จ่าย+ลง |
| 6–12 | ตอน 1 = ฐาน+สะดุด · ตอน 2 = ช่องว่าง · ตอน 3 ถึง `n-1` = บีบแบ่งเป็นองก์ **แต่ละองก์จบด้วยความล้มเหลวที่แพงกว่าเดิม** · ตอนสุดท้าย = จ่าย+ลง |

**และทุกตอนต้องครบหกช่องในตัวเองด้วย** ซีรีส์มีหกช่องหนึ่งชั้น ตอนมีอีกชั้น

### กติกาที่ห้ามพลาด
- **สะดุดมาก่อนเสมอ** — คลิปสั้น: ก่อนวินาทีที่ 3 · คลิปยาว: ใน 15 วินาทีแรก
- **คลิปยาวเกิน 3 นาที: ย้ำช่องว่างด้วยคำถามที่แคบลงทุก ~90 วินาที** ไม่งั้นคนออกกลางทาง
- **ทุกตอนของซีรีส์จบด้วย cliffhanger** ที่ยังไม่ตอบ และตัดดำทันที ห้ามเฟด
- **ช่องจ่ายต้องมาก่อนจบอย่างน้อย 60 วินาที** ไม่งั้นตอนจบรู้สึกรีบ
- **เชื่อมด้วย "แต่" หรือ "เพราะฉะนั้น" ≥ 2 จุด** ถ้าเชื่อมด้วย "แล้วก็" ทั้งเรื่อง = รายงาน ไม่ใช่เรื่อง
- **CTA เดียว โตออกมาจากช่องลง** ตัดทิ้งแล้วเรื่องยังจบสมบูรณ์ = วางถูก
- **ตัวเอกคือคนดูหรือคนในเหตุการณ์** แบรนด์เป็นเครื่องมือ ไม่ใช่พระเอก

## 9. สคริปต์พากย์

| ค่า | กติกา |
|---|---|
| จำนวนบรรทัด | 1 บรรทัด = 1 คลิป |
| ความยาว/บรรทัด | คลิป 10 วิ → พูด 8.6–9.8 วิ · คลิป 15 วิ → พูด 10–12 วิ เว้นหัวท้ายให้ SFX |
| ยาวเกิน | **ตัดคำออกแล้วอัดใหม่ ห้ามเร่งความเร็วเสียง** ห้าม atempo ห้าม pitch shift |
| ตัวเลข | เขียนเป็นคำอ่าน `2436` → `สองสี่สามหก` ไม่งั้น TTS อ่านเพี้ยน |
| เสียง | **ล็อก voice id ตัวเดียวทั้งเรื่อง** อย่าเปลี่ยนกลางเรื่อง |
| ทดสอบ | **ยิง 1 บรรทัดฟังก่อนเสมอ** โดยเฉพาะภาษาไทย ผ่านแล้วค่อยยิงที่เหลือ |
| ซับ | จับเวลาจาก **ไฟล์เสียงจริง** แล้วค่อยแทนคำด้วยสคริปต์ ไม่ใช่กะเวลาจากสคริปต์ |

## 10. ความจริงและความปลอดภัย

- **ห้ามแต่งตัวเลข ชื่อเคส คำพูด ผลลัพธ์** ที่ไม่มีข้อมูลจริง → เขียนเป็น `[ต้องยืนยัน: …]` แล้วเล่าต่อรอบช่องนั้น
- **แยกให้ชัดระหว่างหลักฐานกับเรื่องเล่า** เอาเรื่องเล่ามาทำหนังได้ แต่**ห้ามเขียนเป็นข้อเท็จจริงในแคปชั่น** ให้ใช้ "ตามที่เล่าสืบกันมา"
- **งานประวัติศาสตร์ไทย: ห้ามวาดพระพักตร์พระมหากษัตริย์และพระบรมวงศานุวงศ์** ใช้ห้องท้องพระโรงว่าง เงา หรือสัญลักษณ์แทน
- **ห้ามอ้างอิงหน้าคนจริงหรือ IP ที่มีลิขสิทธิ์** ภาพอ้างอิงที่ผู้ใช้อัปโหลดใช้เป็น "ตัวอย่างสไตล์" เท่านั้น
- **ไม่ใส่ข้อมูลส่วนตัวหรือความลับลงใน prompt**
- **งานสายสุขภาพ/คลินิก:** ห้ามเขียนคำรับประกันผลหรือกรอบเวลาที่เอกสารอ้างอิงไม่ได้พูดไว้

## 11. เช็กลิสต์ก่อนปล่อย

- [ ] จำนวนคลิปครบตามสูตร ไม่มีช่องโหว่ ไม่มีตอนที่ขาดคลิป
- [ ] **ทุก prompt มีบรรทัด `ELEMENTS` `CAMERA` `LIGHT` `SFX` ครบสี่บรรทัด**
- [ ] **ทุก `SFX` ในprompt ครบ 3 ชั้น และผูกกับช็อตว่าเสียงไหนอยู่ตรงไหน**
- [ ] **ทุก `ELEMENTS` มีท่อน "สิ่งที่ห้ามมีในเฟรม"**
- [ ] `WD` ในprompt ตรงกับสภาพสะสมของคลิปนั้น ไม่มีแผลหายกลางเรื่อง
- [ ] หน้าตัวละครตรงกับ character sheet ทุกคลิป
- [ ] `aspect` และ `resolution` ตรงกันหมด ไม่มีคลิปหลุดสัดส่วน
- [ ] ไม่มีคลิปไหนที่ตัวละครขยับปากพูด (ถ้าใช้พากย์แยก)
- [ ] ไม่มีดนตรีหลุดเข้ามา (ถ้า `music: false`)
- [ ] ไม่มีตัวหนังสือ ลายน้ำ หรือโลโก้ในภาพ
- [ ] พากย์เสียงเดียวกันทุกบรรทัด ไม่มีบรรทัดไหนถูกเร่ง/ยืด
- [ ] ซับจับเวลาจากไฟล์เสียง ไม่ใช่จากสคริปต์
- [ ] ทุกตอนมีสะดุดตามกำหนด และตอนซีรีส์จบด้วย cliffhanger
- [ ] ช่องจ่ายมีจริง ระบุได้ว่าเสียอะไร
- [ ] CTA เดียว ตัดทิ้งแล้วเรื่องยังจบ
- [ ] ทุก `[ต้องยืนยัน]` ถูกเคลียร์หรือถูกเขียนออกจากสคริปต์แล้ว
- [ ] ไฟล์ส่งมอบเป็นไฟล์เดียวจบต่อหนึ่งตอน ไม่ใช่คลิปแยก
